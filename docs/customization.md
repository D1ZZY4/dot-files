# Customization Guide

This setup is edited in small, focused modules. Prefer the preference files below for everyday changes; edit TOML or Fish sources when you need deeper control.

## Preference files

Three plain-text files control the most common options. Each supports `#` comments. After editing, apply changes as noted.

| File | Purpose | Apply changes |
|------|---------|---------------|
| `~/.config/starship/style` | Prompt separator style `1`–`5` | `starship-rebuild` |
| `~/.config/starship/color` | Palette name (`moonlight`, `catppuccin-macchiato`) | `starship-rebuild` |
| `~/.config/starship/username` | Custom Fastfetch welcome name | `fastfetch-apply-welcome` or new shell |

**System username (default):** leave `username` empty (comments only). Fastfetch shows `Welcome, {user-name}!`.

**Custom welcome name:** add one line, for example `Alex`, then run:

```fish
fastfetch-apply-welcome
```

Or use the helper command:

```fish
starship-dotfiles --username "Alex"
starship-dotfiles --username reset   # back to system username
```

Equivalent flags: `starship-dotfiles --style 5`, `starship-dotfiles --color moonlight`.

## Fish

Fish files install under:

```text
~/.config/fish/
```

| Path | Role |
|------|------|
| `conf.d/` | Startup fragments (loaded automatically) |
| `functions/` | Commands such as `starship-dotfiles`, `ls`, `starship-rebuild` |
| `config.fish` | Minimal entry point |

Recommended practice:

- Environment variables in `conf.d/`
- Reusable commands in `functions/`
- Keep `config.fish` minimal

## Starship

Modules live under:

```text
~/.config/starship/modules/
```

After editing any module:

```fish
starship-rebuild
```

### Separator styles

| Style | Appearance |
|-------|------------|
| 1 | `█ ... █` |
| 2 | `░▒▓ ... ▓▒░` |
| 3 | Angled powerline |
| 4 | Slant powerline |
| 5 | Round powerline (default) |

Set via `~/.config/starship/style` or:

```fish
starship-dotfiles --style 5
```

### Color themes

Palettes are defined in `~/.config/starship/colors/`. Set the active name in `~/.config/starship/color` or:

```fish
starship-dotfiles --color catppuccin-macchiato
```

## Directory icons

Directory icons are in `config/starship/modules/directory.toml`.

Starship `directory.substitutions` performs string replacement, not strict segment matching. Avoid overly generic keys such as `test` or `cache` when they could match unrelated paths.

Prefer specific entries:

```toml
".venv" = " .venv"
".pytest_cache" = "󰙨 .pytest_cache"
"node_modules" = " node_modules"
```

## Dev Tools block

The Dev Tools block is generated by:

```text
~/.config/fastfetch/dev-tools.fish
```

It lists tools found on `PATH` (Node.js, package managers, Python, Git, Docker, and others). Missing tools are omitted.

To add a tool, edit `dev-tools.fish`: add a version variable and an `__tool_line` entry in the appropriate section.

Python versions are discovered from executables named `python3.x` on `PATH`.
